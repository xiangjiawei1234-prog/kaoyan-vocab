# 考研英语 / 四六级背单词

四本真题词书的纯静态背单词网页。打开即用，无需注册、后端或构建；可安装为 PWA 离线背诵。学习进度只保存在当前浏览器，不上传任何数据。

|:--|--:|:--|--:|
| 考研英语 | 7,997 | 46 套考研真题（1998–2026） | 3 |
| 英语四级 | 7,167 | 80 套四级真题（2014–2026） | 5 |
| 英语六级 | 8,821 | 83 套六级真题（2013–2026） | 4 |
| 综合词书 | 12,082 | 以上三书按单词去重合并 | 3 |

**在线使用：<https://xiangjiawei1234-prog.github.io/kaoyan-vocab/>**

**离线下载：** 到 [Releases](https://github.com/xiangjiawei1234-prog/kaoyan-vocab/releases/latest) 下载 zip，解压后双击 `index.html` 即可（推荐最新版 Chrome / Edge / Safari / Firefox）。

## 功能

- **四本词书，独立进度**：顶部「词书」切换；每本书的进度、熟练、收藏、统计与学习设置互不影响。综合书同词只背一次，并标注考试来源。界面偏好可选择「此设备通用 / 本书单独」，本页词书、下次默认与跨页跟随分开控制，切书不再覆盖已有的本书偏好。
- **阅读与操作定制**：卡片密度、判定后阅读顺序、卡片信息开关、固定次级动作；按键（含 Shift 组合）、四额外动作、触摸手势（可关/反转/分阶段映射）与左右手布局；所有入口共用同一动作守卫与连击保护。
- **三档背诵视图**：首页直接切换沉浸／简洁／标准，信息量逐级增加；沉浸保留词卡与必要操作，常用工具和导航随时可展开。模式可记住并选择设备通用／本书单独；米纸、暖炭黑与深棕组成纸感主题，深浅主题同步，页头只保留文字标题。
- **设置方案**：学习计划、词库范围、外观与操作偏好可分别保存为方案，支持内置方案与导入 / 导出；应用前逐项校验，不影响当前组与学习记录。
- **艾宾浩斯 10 档复习**：默认 1 / 2 / 4 / 7 / 10 / 15 / 21 / 30 / 45 / 60 天，可选轻负荷、短期强化等预设或逐档自定义；改设置只影响下一组，不追溯已有到期时间。
- **学习负荷控制**：每日新词、单日复习上限、每组词数、积压保护、完成页临时加量；主组完成后可挂机自动续背（可取消、可按书暂停当天），空学习页也可显式「开始等待到期」，有到期/额度恢复时按同一方案续背。
- **微学习与安心收工**：学习上下文条可设「学 5 词就停」临时停靠目标（只计不同词，改判/重考不重复），达标后选择「先休息」或「继续」；「保存并休息」会先保存学习记录与当前组现场，刷新后回到同一张卡；完成页／空页还可显式开始只含到期词的 5 词纯复习小组（不学新词、不占新词额度）。
- **判定与复习**：先判「会 / 不会」再揭示释义，快捷键/滑动最多改判一次，再改请点击按钮；可撤销；不会的词本组队尾重考；熟练词长期移出背诵与复习。完成页区分本组词数、判定次数与当前范围掌握数；较长普通提示可收起，悬停或聚焦阅读时暂停计时。
- **学习辅助**：错词特训、拼写专项（只看中文释义拼写）、学习热力图、学习时长统计、连击保护、刷新后继续未完成的一组、详情页「本词问题」本地记录与导出。单词与英文例句可分别朗读，支持正常／慢速／停止与播放状态；通过设备系统语音播放，不写学习记录、不代判定。
- **筛选与统计**：词频直方图双端筛选、套卷覆盖 / 大纲 / 词性筛选；统计页含掌握率、未来 14 天复习负荷、词频分层掌握度、近 14 天学习量、乱序历史首次自评（Wilson 95% 区间）；可从复习负荷/词频层/阶段档直达对应词表，返回保留统计现场。
- **词表与导出**：短横屏优先展示单词结果，搜索、筛选和管理仍直接可用；中英文搜索、熟练 / 错词筛选、虚拟列表键盘导航、例句点词查义；可保存常用筛选视图、按当前筛选全量批量收藏/熟练（熟练先预览确认）；支持导出 TXT（全范围或筛选结果）、按词数 / 份数拆分并打包 ZIP。
- **备份**：设置页支持最多20份命名网页内存档，逐份恢复、下载与删除；备份 v3 导入导出（含四本书与学习设置）；导出只读、导入整份校验并展示替换范围、损坏记录可救援导出、高于当前数据版本的备份拒绝导入。
- **离线与可访问性**：PWA 整组缓存，安装后断网可用；支持标准 / 大字阅读、键盘与读屏操作、设备 TTS 发音与语速调节。
- **内容口径**：词频按真题正文统计（去除 Directions、章节标题、答题说明）；四书例句 100% 覆盖，界面区分「真题例句」与「自编例句」；四书 96 条语境义（98 义项）附真题原句与出处。

## 本地运行

直接双击 `index.html` 即可离线使用。需安装 PWA 或调试 Service Worker 时，起一个本地静态服务：

```bash
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

换浏览器或清理缓存前，请在「设置 → 备份与存档 → 导出进度文件」备份。

## 验收

```bash
node --max-old-space-size=512 scripts/verify.mjs
```

共 52 项检查（应用测试 + 词库校验，含背诵三模式、网页内存档、保存并休息／微学习／听读控制专项）。当前版本 v73 / 资源 `20261028-r68`。测试不启动浏览器，用 Node DOM 桩 / vm 沙箱执行真实页面脚本，不复制业务逻辑。独立真实浏览器检查在 `tests/browser/`（默认汇总不启动浏览器）。

## 词库数据规则（改词库前必读）

- 词库是 11 元组数组：`[word, phonetic, meaning, posIdx, r, f, c, example, source, ky, fm]`，**数组顺序就是该书的进度主键**。
- 新增词只能追加到数组末尾；删除或重排中间词条必须 bump 该书 `dataVersion`，并在 `migrations` 里记录 `removed / removedWords / previousWordCount`（有新增时另记 `added / addedWords`），旧进度按迁移修复。
- 例句优先同书真题原句，跨书真题句要注明来源；没有真题原句时用 `自编` 例句，不得把自编例句标成真题。
- 修改 `js/`、`css/` 或 `index.html` 后，必须同步更新 `sw.js` 的 `CACHE` 与 `index.html` / `sw.js` 里的资源 `?v=`，否则 PWA 会继续读旧缓存。
