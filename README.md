# 考研英语 / 四六级背单词

一个纯静态的背单词网页：考研英语、英语四级、英语六级三本真题词书，外加一本合并去重的综合词书，共 8,043 / 7,201 / 8,853 / 12,144 词。打开 `index.html` 即可使用，无需安装、无需注册，也可装成 PWA 离线背词。

## 功能

- **四本词书，进度独立**：顶部「词书」按钮切换；每本书的进度、熟练、收藏、统计与学习设置互相独立。
- **艾宾浩斯复习**：10 档间隔（5 分钟 → 60 天，约 120 天走完一轮）；「会」升档、「不会」归零并在本组队尾重考。
- **乱序掌握率估计**：乱序模式下按随机抽样实时显示当前词书的掌握率估计（Wilson 95% 置信区间 + 样本量）；只统计首次作答的新词，每本书独立。
- **熟练词永久移出**：手动标记后不再进入背诵 / 复习队列；词表与统计页可取消标记。
- **错词特训**：独立错词队列，只调整错误次数，不占每日新词额度，不打断正常复习节奏。
- **词表、统计与热力图**：按套卷覆盖、词频、大纲词、状态筛选；统计页含近 12 周学习热力图与复习安排。
- **进度备份**：导出 / 导入学习记录（v3 备份包含全部词书，兼容旧版 v1 / v2 备份，旧词库进度自动迁移）。
- **TXT 导出**：按背诵范围或词表筛选结果导出纯单词列表，可拆分多份并打包成 ZIP 下载。
- **离线可用**：通过本地静态服务打开后可安装为应用，断网也能背。

## 词书

| 词书 | 词数 | 词库文件 | 语料 |
|:--|--:|:--|:--|
| 考研英语 | 8,043 | `js/words-data.js` | 46 套考研真题（1998–2026） |
| 英语四级 | 7,201 | `js/cet-words-data.js` | 80 套四级真题（2014–2026） |
| 英语六级 | 8,853 | `js/cet-words-data.js` | 83 套六级真题（2013–2026） |
| 综合词书 | 12,144 | `js/combined-words-data.js` | 三书合并去重，共 209 套卷 |

词条包含音标、词性、释义、真题例句、词频与套卷覆盖；每本书的数组顺序就是学习进度的主键，调整词库时需升级对应 `dataVersion` 并补齐迁移记录，避免旧进度错位。

## 打开方式

- **双击 `index.html`**（最省事，完全离线可用）。
- **本地静态服务**：在本目录执行 `python3 -m http.server 8765`，浏览器访问 `http://127.0.0.1:8765/`（推荐；可安装为应用并启用离线缓存）。

三种考试都要准备时选「综合词书」：同名单词只出现一次，卡片与详情标出考试来源，词频和套卷覆盖按三类考试合并；综合书进度独立，不自动合并旧书进度。

## 独立小工具

| 工具 | 用途 |
|:--|:--|
| `tools/collocation/` | 完形填空固定搭配 166 条记忆卡片 |
| `tools/ebbinghaus-plan/` | 按开始日期与每日新词量生成复习计划表 |
| `tools/wordfreq-viz/` | 真题词频分布、Zipf 曲线与检索 |
| `tools/long-sentence/` | 28 句真题长难句拆解练习 |
| `tools/writing/` | 作文模板与高分句型库（小作文 9 类 + 大作文 4 类 + 高分句型 50 条） |

每个工具双击各自目录下的 `index.html` 即可使用，与主应用互不影响、不共享学习进度。

## 说明

- 纯静态 HTML / CSS / JS，无构建、无外部依赖；学习进度保存在浏览器 localStorage。
- 词频与例句来自公开真题语料的统计整理，词库释义参考 ECDICT；本仓库不包含真题原文与语料源文件。
- 词库数据版本与迁移记录内嵌在对应的 `js/*-words-data.js` 中，旧进度与旧备份可自动迁移。
