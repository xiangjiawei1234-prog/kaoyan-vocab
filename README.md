# 考研英语 / 四六级学习资料

## 背单词网页（主应用）

**打开 `index.html`**（多文件新版，支持本地静态服务或直接双击；可安装为 PWA 离线使用）。

**在线使用（免安装）**：<https://xiangjiawei1234-prog.github.io/kaoyan-vocab/> —— 浏览器直接打开就能背；在浏览器菜单选「安装应用 / 添加到主屏幕」后可离线使用。

- **四本词书，自选背诵**（顶部「词书」入口切换，进度/熟练/收藏/统计各书独立）：
  - 考研英语 **7,997 词**，基于 46 套考研真题词频
  - 英语四级 **7,168 词**，基于 80 套四级真题（2014–2026）词频
  - 英语六级 **8,821 词**，基于 83 套六级真题（2013–2026）词频
  - **综合词书 12,083 词**，合并以上三书并按单词去重；同词只背一次，展示考试来源，词频与套卷覆盖相加。综合书的学习记录独立，不自动合并旧书进度。
  - 四/六级词库已做人工审查：删除 OCR 碎片、缩写代号、人名地名、无独立词义的屈折形与极冷门专业词；2026-10 更新又做正文口径词频、错形归并和释义/例句复核。
  - **词频口径**：按真题正文统计（去除 Directions、章节标题、答题说明），归并 `data/species/politics/tax/code/cope/clothes/ethics/statistics` 等错形；词频排名 `r` 随修正后词频重排。
  - **释义**：考研高频多义词按真题考义排序；四六级重叠词复用考研精修释义，并用四六级真题证据调整首位义。
  - **例句**：四书 100% 覆盖；优先真题原句（允许跨书来源并标注），无真题原句时使用 `自编` 例句，界面会区分「真题例句」与「自编例句」。
- 艾宾浩斯 10 档复习（5 分钟 → … → 60 天，约 120 天走完）
- **词频直方图筛选**：设置页以对数刻度直方图显示当前筛选池的词频分布；拖动下方轨道两端的圆点即可框选上下界（也可直接点轨道），实时显示区间内外词数与可背词数。轨道两端标注低频/高频，新增 `≤5 / ≤10 / ≤20 次` 上界预设，可一键剔除高频熟词、节约背诵时间。
- **乱序历史首次自评**：只统计乱序模式下首次作答的新词，显示历史样本中「首次就会」的比例与 Wilson 95% 区间。样本来自各次筛选，**不代表当前范围或全书掌握率**；每本书独立。
- **统计页看板**：总览新增掌握率堆叠进度条与今日新词配额；新增未来 14 天复习负荷柱状图、词频分层掌握度（高频/中高频/中频/低频/仅 1 次）；近 14 天学习量按新词/复习堆叠并给出 14 天正确率，抽样面板增加 Wilson 区间色带。
- 词表 / 统计 / 设置 / 导入导出进度（备份 v3 含全部词书；兼容旧版 v1/v2 备份，旧词表进度自动迁移）。导入前展示备份时间、各书记录量与替换范围；高于当前词库版本的备份会被拒绝，损坏词书不会伪装成空白记录，可另行救援导出。
- **熟练**：点击「熟练」或按 `M`，移出背诵与复习；词表筛选「熟练」可取消标记，统计页可清空当前词书的熟练标记。刷新、换顺序及导入旧备份不会让熟练词重新入队。
- **错词特训**：独立错词队列，只调错次、不占新词额度、不扰主背诵队列；背诵页 / 词表「错词本」均可进入。
- **学习热力图**：统计页近 12 周学习量格子图。
- 词表点击单词查看完整释义、例句与词形，保留正在进行的背诵队列。
- **导出 TXT**：设置页导出当前背诵范围（含全部匹配词，不受每日上限截断，排除熟练词）；词表页可导出当前搜索与筛选结果。每行只有一个单词。
- **拆分导出 TXT**：上述两个位置都有「拆分导出 TXT」，支持按每份词数或指定份数均分，预览各份词数与范围。可逐份下载，也可打包成 ZIP 一次下载全部；例如 8,000 词设每份 4,000 词，即得到两份 TXT。
- **2026-10 词库清理与修复**：先按原文证据删除 74 条残缺词形、OCR 碎片、网址/专名及外语短语片段（考研 57 / 四级 6 / 六级 11）；再修复 118 条卷面词/错形/碎片并补入正确词形（考研 50 删/4 增、四级 35 删/2 增、六级 33 删/1 增）；原有进度和旧备份自动迁移。清单见 `scripts/wordbook-cleanup-20261021.json` 与 `scripts/wordbook-repair-20261021.json`。
- 进度保存在当前浏览器；换浏览器前请导出备份。导入替换学习记录并保留已有熟练标记；导入中途写入失败会整份回滚，并保留恢复日志。
- **词表与键盘**：手机端搜索/筛选压成一行，导出收进菜单；每本词书保留搜索、筛选、滚动位置与活动行。虚拟列表只有一个 Tab 停靠点，方向键换行、Home/End 定位并播报位置；例句整句一个键盘入口，方向键选词、回车查义、Esc 返回。设置页可关闭单字符快捷键，Enter、方向键和按钮仍可用。

使用说明见 `docs/user-guide.md` 与 `docs/cheatsheet.md`；架构见 `docs/architecture.md`。

```
index.html                   主页面（背诵 / 词表 / 统计 / 设置）

js/txt-zip.js                TXT 分片 ZIP
assets/icons/                PWA 图标
manifest.webmanifest / sw.js PWA 清单与离线缓存
docs/                        用户指南、速查表、架构
tests/fixtures/              测试夹具（拼写修复、CET 卷次清单）

scripts/verify.mjs           一键验收
scripts/build-combined.mjs   重建综合词书
scripts/wordbook-*.json      数据清理 / 修复证据
```

## 开发验收

```bash
node --max-old-space-size=512 scripts/verify.mjs
```

- 测试不启动浏览器，用 Node DOM 桩 / vm 执行真实页面脚本；校验报告写入 `tests/reports/`。
- 词库数组顺序就是进度主键：新增词只能追加到末尾；删除必须 bump `dataVersion` 并记录 `removed/removedWords/previousWordCount` 迁移。
- 修改 `js/`、`css/` 或 `index.html` 后，必须同步 bump `sw.js` 的 `CACHE` 与资源 `?v=`，否则 PWA 会继续读旧缓存。
