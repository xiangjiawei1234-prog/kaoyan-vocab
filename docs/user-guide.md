## 1. 快速开始

### 1.1 打开方式（二选一）

| 方式 | 操作 | 说明 |
|:--|:--|:--|
| 双击 | 打开仓库根目录的 `index.html` | 最省事，离线可用 |

### 1.2 第一次打开学什么

默认设置已经可直接开背：

- 每日新词 30 个
- 顺序：按词频顺序（高频词先背）
- 词库范围：词频不限 × **至少 2 套卷**（推荐）
- 今日队列 = 到期复习 + 新词（复习优先穿插）

建议第一周就按默认节奏走，别急着改筛选。

## 2. 背诵流程

### 2.1 两阶段操作（核心）

每个词分两步，**不需要先点“显示答案”**：

1. **只看单词** → 凭记忆直接按「会」或「不会」。立刻出中文释义。
2. **看释义后** → 确认无误就按「下一个」翻页；发现判错了就按另一个键**改判**。

按钮位置与键盘一致：**「会」在左（`F`），「不会」在右（`J`）**。

手机端也可以：卡片**右滑 = 会，左滑 = 不会**（仅在判定前有效）。

### 2.2 为什么必须先判定才能翻页

| 阶段 | 能做什么 | 按「下一个」/空格 |
|:--|:--|:--|
| 未判定（只看单词） | 会 / 不会 / 发音 / 收藏 / 熟练 | **不翻页**，提示「请先选择会或不会」 |
| 已判定（释义已出） | 改判 / 撤销 / 下一个 | 进入下一词 |

原因：

- 先回忆、再对答案，才有记忆效果。空格一按就过 = 假学习。
- 每次判定都会写入复习计划和统计。跳过判定会让档位和正确率失真。

### 2.3 改判与撤销

| 操作 | 怎么做 | 结果 |
|:--|:--|:--|
| 改判 | 判定后按另一个判定键（如先 `F` 再按 `J`） | 进度**回滚后按新判定重算**，不会重复计数 |
| 撤销 | `Ctrl/⌘ + Z`，或点「撤销」按钮 | 可撤销判定、改判、翻页，一步一步回退 |

改判后仍停在当前词，需手动翻页。撤销到最前一步后会回到“未判定”状态，重新面对这个单词。

### 2.4 判「不会」之后

- 该词回到第 0 档，**5 分钟后**重新入队复习。
- 同时在**本组队尾重考**一次（每个词每组最多重考 2 轮）。
- 统计里错词计数 +1，进入「错词本」。

### 2.5 艾宾浩斯 10 档

「会」升一档，「不会」归零。走完全部档位约 **120 天**。

| 档位 | 答对后多久再见 | 累计节奏 |
|:--|:--|:--|
| 1 | 5 分钟 | 当天 |
| 2 | 30 分钟 | 当天 |
| 3 | 12 小时 | 次日 |
| 4 | 1 天 | 第 2 天 |
| 5 | 2 天 | 第 4 天 |
| 6 | 4 天 | 第 8 天 |
| 7 | 7 天 | 第 15 天 |
| 8 | 15 天 | 第 30 天 |
| 9 | 30 天 | 第 60 天 |
| 10 | 60 天 | 第 120 天 |
| **已掌握** | 60 天档答对后 | 不再安排复习 |

背诵卡片下方的 10 个小圆点就是当前档位进度。

### 2.6 三种背诵顺序（设置页切换）

| 顺序 | 新词 | 复习 |
|:--|:--|:--|
| 按词频顺序 | 词频排名从前到后 | 到期时间早的优先 |
| 乱序 | 每次开始新一组重新抽随机 | 同上，整组一起打乱 |
| 错词优先 | 仍按词频 | **历史错误次数多的优先** |

> 乱序是真乱序：每次开页、每次开始新一组都重新抽种子，避免靠“记位置”形成虚假记忆。同一组内顺序稳定，不会中途跳动。

**乱序模式 · 掌握率估计（实时）**

乱序模式下新词按随机顺序出现，相当于每次都在词书里随机抽查。背诵页统计条会多出一个「掌握率估计」格子，统计页也有同名面板。

- **统计口径**：只算**乱序模式下第一次作答的新词**——答「会」记为已掌握，答「不会」记为未掌握。复习词、错词特训、按词频顺序/错词优先顺序答题都不计入，避免采样偏差。
- **显示内容**：样本比例（点估计）、95% 置信区间与样本量。样本越多区间越窄，估计越稳。
- **按书独立**：每本词书各自累计；切换词书不会混用样本。换浏览器或清浏览器数据会丢失抽样统计。
- **从头再抽**：设置「重置全部进度」会连同当前词书的抽样统计一起清空。
- **小提示**：如果先按「按词频顺序」背了一大段再切到乱序，剩下的新词会偏难，估计可能偏低；从新词书开始就用乱序时最准。

### 2.7 错词特训（专攻易错词）

只刷「错词本」里的词，**独立队列**，不打断当天的正常背诵。

**三个入口，任选其一：**

1. **背诵页**：统计条下方点「错词特训」。
2. **完成页**：一组背完后，若错词本非空，点「错词特训」。
3. **词表**：状态筛「错词本」→ 点「一键特训（N）」。

**队列怎么排：** 按历史错次从多到少；错次相同则高频词先来。不看当前词库筛选。

**判定规则（和普通背诵不同）：**

| 按键 | 结果 |
|:--|:--|
| 「会」 | 错次 **−1**（减到 0 自动离开错词本） |
| 「不会」 | 错次 **+1**，继续留在错词本 |

特训**只改错次**：

- **不动**学习档位、下次复习时间、今日新词额度。
- 当日学习量和正确率照常计入。
- 可改判、可撤销，和普通背诵一样。

**退出还原：** 点「退出特训」（或卡片上的同名按钮），**回到进入前的主背诵队列**，进度原样接上。特训练完一组后可点「再练一组」接着刷。

错词本为空时按钮不可点，提示先在背诵中积累错词。

## 3. 熟练标记

已经认识、不想再背的词，标为「熟练」。

| 项目 | 说明 |
|:--|:--|
| 何时用 | 看到单词 1 秒内就认识，再背纯属浪费时间 |
| 怎么标 | 背诵卡片按 `M` 或点「熟练」；词表每行「标为熟练」；单词详情里也有 |
| 效果 | **永久移出**背诵、复习、乱序、错词重考队列；不占每日新词配额 |
| 怎么取消 | 词表把状态筛成「熟练」→ 点「取消熟练」；或在单词详情里取消 |
| 批量取消 | 统计页 →「清空熟练标记」（学习进度和收藏都保留） |
| 取消之后 | 按**原来的复习进度**恢复，不会从零开始 |

注意事项：

- 熟练名单**单独存放**（按单词文本记），刷新页面、换顺序、导入旧备份都不会让熟练词重新入队。
- 多个标签页同时用：普通保存不会覆盖熟练名单；各标签的熟练操作会合并。
- 标熟练后会清空当前可撤销的操作，避免撤销把词“救”回队列。

## 4. 词表与搜索

词表页默认显示**当前背诵范围**内的词（与顶部词数一致），按词频排名排列。

### 4.1 搜索框

输入英文或中文释义片段即可过滤，例如 `abandon`、`放弃`。

### 4.2 状态筛选

| 选项 | 含义 |
|:--|:--|
| 全部状态（不含熟练） | 默认视图 |
| 待学习 | 未标熟练的全部词 |
| 未学 | 从未判定过 |
| 学习中 | 有进度但未走完 10 档 |
| 到期复习 | 已到复习时间且未掌握的词，按到期先后排列；自动刷新，排除熟练词 |
| 已掌握 | 走完 10 档 |
| 熟练 | 只看熟练词（可在此取消标记） |
| **错词本** | 历史判定出过错的词；在此可点「一键特训」进入错词特训 |
| 收藏 | ★ 收藏过的词 |

### 4.3 词库范围筛选

| 选项 | 含义 |
|:--|:--|
| 当前背诵范围 | 跟随设置页的词库筛选 |
| 全部词库 | 不受筛选限制 |
| 高频（≥5 次） | 46 套真题里出现 ≥5 次 |
| 冷门（≤2 次） | 出现 ≤2 次 |
| 考研大纲词 | 仅大纲内词汇 |

### 4.4 查看详情

点**单词本身**打开详情浮层：音标、释义、真题例句、词形变化、词频与套卷覆盖、当前档位和下次复习时间。已到期、未学、已掌握及熟练词会分别提示。

- 详情里可直接：标/取消熟练、收藏/取消收藏、发音。
- **查看详情不会打断当前背诵队列**，关掉浮层继续背。
- **例句点词查义**：卡片或详情里的真题例句，点任意英文单词即弹出该词释义（词库内附音标与词频，可再点「详情」）。点空白处或按 `Esc` 关闭。词库未收录的词会提示。

### 4.5 收藏

背诵时按 `B`（或点右上角 `★`）。收藏只是个人书签，不影响复习调度。统计页显示收藏数。

### 4.6 导出每行一词的 TXT

- **设置 → 词库筛选 → 导出当前背诵范围 TXT**：按词频区间、试卷覆盖、大纲和词性条件导出，排除熟练词。导出全部匹配词，不受每日新词上限或词表搜索影响。
- **词表 → 导出筛选结果 TXT**：导出当前搜索、状态、范围筛选后的结果，例如收藏、错词本或到期词；选择「熟练」时也可导出熟练名单。
- 文件不包含标题、释义、音标或序号，每行只有一个英文单词。空范围会提示调整条件；导出不改变背诵队列或学习记录。

### 4.7 拆分导出 TXT

在设置页或词表页点击「拆分导出 TXT」，再选择拆分方式：

- **按每份词数**：例如 8,000 词填 `4000`，得到两份各 4,000 词；8,001 词则得到 4,000 / 4,000 / 1 词三份。
- **按份数均分**：例如 8,000 词分成 3 份，得到 2,667 / 2,667 / 2,666 词，各份最多相差一个词。

窗口会预览每份词数和连续范围，文件名包含份号与范围，顺序不变，不重不漏。可逐份点「下载 TXT」，或点「打包下载全部（ZIP）」后解压使用，避免浏览器阻止一次下载多个文件。每个 TXT 仍为每行一词，无表头、释义和 BOM。

预览以打开窗口时的导出范围为准；需要更改词库筛选或搜索时，关闭窗口后调整，再重新打开。大量分片按每页 20 份显示，ZIP 始终包含全部分片。

## 5. 统计页怎么读

### 5.1 总览数字

| 指标 | 含义 |
|:--|:--|
| 已掌握 | 走完 10 档的词（仅当前范围） |
| 学习中 | 有进度、未掌握 |
| 未学 | 当前范围内还没开始的词 |
| 熟练（全词库） | 熟练标记总数（跨范围统计） |
| 错词 | 曾判过「不会」的词数 |
| 收藏 | ★ 数量 |
| 连续打卡 | 连续有学习记录的天数 |
| 学习天数 | 有记录的总天数 |
| 累计正确率 | 全部判定中「会」的占比 |
| 累计时长 | 页面累计学习时间 |

### 5.2 三个图表

图表前的**复习安排**显示当前背诵范围内已到期词数、未来 24 小时新到期词数，以及下一批复习的具体时间。点「查看到期词」会打开对应词表，保留当前背诵队列。熟练词和已掌握词不计入复习安排。

- **掌握阶段分布**：第 0～10 档各有多少词。柱子越高词越多。多词堆在 1–3 档说明刚起步；堆积在 8–10 档说明快收割了。
- **近 14 天学习量**：每天学习次数（新词 + 复习）。悬停可看当天新词/复习拆分。
- **学习热力图（近 12 周）**：一格一天，颜色越深当天练得越多（新词 + 复习总次数）。悬停或键盘 `Tab` 聚焦格子，看当天次数和新词/复习拆分。行 = 周日到周六，列 = 周；未来日期留空。

看趋势比单看某天有用：连续浅色说明该补量了；深色扎堆要警惕是否熬夜硬刷。

### 5.3 随机抽样 · 掌握率估计

只有乱序模式下才会累积样本。面板显示当前词书的掌握率点估计、95% 置信区间和样本量，口径与上文的「乱序模式 · 掌握率估计」一致：

- 只统计乱序模式里第一次作答的新词（会 / 不会），复习与错词特训不计。
- 样本按词书独立保存，切换词书不混用；抽样统计不写入进度备份。
- 「重置全部进度」会连同当前词书的抽样一起清空。

### 5.4 进度管理

「导出进度 / 导入进度 / 清空熟练标记 / 重置全部进度」都在本页底部，详见下一节。

## 6. 设置

### 6.1 每日新词上限

- 范围 1–500，默认 30。
- 只限制**新词**；到期复习不受限，来了就得还。
- 改小不影响已学词的复习节奏。

### 6.2 词库筛选（决定“背哪些词”）

四项可自由组合，右上角实时显示当前范围词数。

| 筛选项 | 说明 | 常用预设 |
|:--|:--|:--|
| 词频区间 | 在 46 套真题里出现次数的范围；上限留空 = 不限 | 全部 / ≥2 / ≥3 / ≥5 / ≥10 次 / 只看冷门(1–2) / 只出现 1 次 |
| 至少出现在几套卷 | **默认 ≥2 套（推荐）**。只在一套卷里反复出现的词，往往只是那套卷的主题恰好如此 | 不限 / ≥2 / ≥3 / ≥5 / ≥10 / ≥20 套 |
| 只保留考研大纲词 | 开关 | — |
| 词性多选 | 名词 / 动词 / 形容词 / 副词 / 其他；**一个都不选 = 不限** | — |

快捷组合：

| 按钮 | 实际条件 |
|:--|:--|
| 核心必考 | 词频 ≥5 次 且 ≥3 套卷 |
| 冷门补充 | 词频 ≤2 次 |
| 只背形容词 | 词性 = 形容词 |
| 恢复默认筛选 | 回到默认范围：词频不限、**套卷 ≥2**、词性不限、大纲关。要全背请把套卷数选「不限」 |

提示：改筛选只影响**新进队列**的词。已标熟练的词不会因此复活。

### 6.3 主题

浅色 / 深色 / 跟随系统。夜间背词建议深色。

### 6.4 显示与发音

- 显示音标、真题例句、词形变化：三个开关。
- 自动发音：每出一个新词自动朗读。用的是浏览器语音，可用嗓音取决于系统，不保证联网。

### 6.5 快捷键自定义

默认键位：

| 动作 | 默认键 |
|:--|:--|
| 会 | `F` |
| 不会 | `J` |
| 下一个 | `空格`（`Enter` 恒等价） |
| 发音 | `S` |
| 收藏 | `B` |
| 熙练 | `M` |

改键步骤：设置 → 按键设置 → 点对应按钮 → 按下新键。

规则：

- 只能绑**单个英文字母、数字或空格**。
- `Enter`、方向键、`Esc`、`Ctrl+Z` 等是保留键，不能占用；冲突会提示。
- 「恢复全部默认」一键还原。

## 7. 进度备份

进度保存在**当前浏览器**（localStorage），不上传、不同步。

### 7.1 什么时候导出

- 换电脑 / 换浏览器 / 重装系统之前。
- 清除浏览器数据之前。
- 打算「重置全部进度」之前。
- 养成习惯：每周导出一次，存到网盘或手机。

### 7.2 怎么导出 / 导入

1. 统计页 →「导出进度」→ 得到 `考研单词进度_YYYY-MM-DD.json`（备份 v3：含考研/四级/六级全部词书）。
2. 新环境打开本页 → 统计页 →「导入进度」→ 选中该 JSON。

导入行为：

| 情况 | 结果 |
|:--|:--|
| 正常备份 | 学习记录被备份**替换** |
| 已有的熟练标记 | **保留**，并入备份里的熟练名单（不会被旧备份取消） |
| 旧版 v1 平铺备份 | 按考研词书导入，不丢进度 |
| 旧版 v2 备份 | 自动按旧词表版本迁移后导入（四/六级进度不丢） |
| 无效 JSON / 异常文件 | **整份拒绝**，当前记录完全不动 |
| 文件过大（>10MB） | 拒绝 |

### 7.3 多设备 / 多标签页

- **不支持云同步。** 两台电脑各自学各自的，靠导出/导入手动合并（以更新的那份为准）。
- 同一浏览器开多个标签：普通保存以**较新的记录**为准，另一窗口会提示“已同步”；熟练名单独立合并，互不抹掉。
- 建议同一时间只在一个标签里背词，减少来回覆盖。

### 7.4 进度“坏了”怎么办

| 症状 | 处理 |
|:--|:--|
| 提示“无法保存 / 保存失败” | 立刻点「导出进度」；再检查浏览器是否禁用了站点存储或磁盘已满 |
| 本地备份损坏（打不开或空了） | 页面会**保护原文件并暂停自动保存**，避免把空数据写回去；独立的熟练名单仍可恢复。此时先导出或导入一份有效备份，或明确点「重置全部进度」后再继续 |
| 误点了「重置全部进度」 | 有导出的 JSON 就导入回来。没有则无法找回——所以先备份再重置（确认框也会提示） |
| 导入了错误文件 | 若被拒绝，什么都没变；若导入成功才发现不对，只能再导入更早的正确备份 |

## 8. 常见问题 FAQ

**Q：进度丢了？**
进度只存在当前浏览器里。换浏览器、清缓存、隐私模式都不会自动迁移。预防办法只有一个：定期「导出进度」。丢失后若从未导出，无法找回。

**Q：熟练词去哪了？**
这是设计如此：熟练词永久退出背诵/复习队列。想找回：词表 → 状态选「熟练」→ 逐个「取消熟练」；或统计页「清空熟练标记」一次性恢复（原学习进度保留）。

**Q：为什么空格不能翻页？**
还没按「会/不会」时，空格和 `Enter` 都会被拦住，并提示“请先选择会或不会”。先判定（`F`/`J`），释义出来后空格才能翻页。这是保证记忆与统计不失真的硬规则。

**Q：改判之后统计会重复算吗？**
不会。改判是**回滚到首次判定前再重算**，正确率和档位不会叠加。撤销（`Ctrl/⌘+Z`）也能逐步退回去。

**Q：手机上怎么用？**
浏览器直接打开 `index.html` 即可，界面已适配窄屏。判定可以用按钮，也可以**右滑=会、左滑=不会**（判定前有效；下滑不会误翻页）。发音依赖手机系统语音。

**Q：一个词今天判了「不会」，什么时候再见？**
5 分钟后入复习队列，同时本组队尾会再考一次（最多 2 轮）。当天做完这组可以点「再来一组」继续。

**Q：为什么有些词我没见过？**
默认范围是「≥2 套卷」。想全背：设置 → 词库筛选 → 套卷数选「不限」；想精简：改「核心必考」；改乱了想回默认范围：点「恢复默认筛选」。

**Q：「已掌握」和「熟练」一样吗？**
不一样。**已掌握** = 走完 10 档复习自然出师；**熟练** = 你手动声明“不用再背”。前者是系统判定，后者是人工快捷操作。两者都不再入队，但来源和取消方式不同。

**Q：发音没声音？**
先点一次页面再试（浏览器要求用户手势）。仍不行则是系统没有英语语音包，或浏览器不支持 SpeechSynthesis。发音非必需。

**Q：可以只背错词吗？**
可以，两条路：

1. **错词特训**（推荐）：背诵页 / 完成页点「错词特训」，或词表筛「错词本」→「一键特训」。独立队列，只调错次，不影响正常复习节奏。
2. **错词优先**：设置 → 背诵顺序选「错词优先」，复习队列按错误次数从多到少排。

**Q：错词特训会打乱我的复习计划吗？**
不会。特训只改错次，不动档位、到期时间和今日新词额度。点「退出特训」就回到进入前的背诵进度。

**Q：热力图颜色怎么读？**
统计页「学习热力图」，近 12 周、一格一天。颜色越深 = 当天学习次数越多。悬停或键盘聚焦格子，看具体次数和新词/复习拆分。没学的天是空格。

**Q：能装到手机桌面 / 断网用吗？**
可以。用本地服务或部署后的网址打开，浏览器菜单选「安装应用」或「添加到主屏幕」。装好后应用壳已缓存，断网也能背。进度仍只存在当前浏览器。

**Q：仓库里的 tools/ 是什么？**
五个独立小工具，不和主应用抢进度：完形搭配卡片、艾宾浩斯计划表、词频可视化、长难句拆解、作文模板。打开方式见 `tools/README.md`。

## 9. 学习建议

| 工具 / 资料 | 怎么配合 |
|:--|:--|
| `tools/ebbinghaus-plan/`（计划表） | 按开始日期和每日新词量，生成纸质/电子复习计划 |
| `tools/wordfreq-viz/`（词频图） | 查某个词的真题词频、覆盖卷别；定筛选范围前可先翻一翻 |
| `tools/collocation/`（搭配卡片） | 单词之外单独背固定搭配，每天 5–10 条 |
| `tools/long-sentence/`（长难句） | 每天拆 1–2 句，划主干再看从句结构 |
| 真题原卷（自备） | 背到的词在真题里见到一次，顶卡片里背三次；做阅读时把生词回查词表看例句出处 |

节奏建议：

1. 每日 30 新词 + 到期复习，大约 40–60 分钟。
2. 早上新词，晚上复习；间隔复习比一次性刷完更有效。
3. 「不会」的词别焦虑，队尾会再考，档位归零也是设计的一部分。
4. 考前 2 个月每天加 10–15 分钟「错词特训」，把历史坑位清掉；配合「错词优先」顺序更狠。
