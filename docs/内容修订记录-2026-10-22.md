## 2. 读音清单（词键控展示层用；已发送 Lead 与 app-core）

短信中提供的结构如下（`app-core` 负责在 `js/app.js` 实现 `WORD_PRON_VARIANTS` / `wordPronVariants(word)`；词库 `ph` 只用主读音，不带斜线）：

```js
WORD_PRON_VARIANTS = {
  "use":      [ {pos:"动", ipa:"juːz"}, {pos:"名", ipa:"juːs"} ],
  "minute":   [ {pos:"名", ipa:"ˈminit"}, {pos:"形", ipa:"maɪˈnjuːt"} ],
  "contract": [ {pos:"名", ipa:"ˈkɒntrækt"}, {pos:"动", ipa:"kənˈtrækt"} ]
}
```

- **use**：三书 + 综合。词库 `ph` = `juːz`（动），名词 `juːs` 仅展示层；主读音在前（与 `posIdx=VERB`、首位释义、例句一致）。
- **minute**：三书 + 综合。词库 `ph` = `ˈminit`（名），形容词 `maɪˈnjuːt` 仅展示层；四级例句为形容词义，已在释义补 `a. 微小的, 细微的`（词库 `ph` 仍取名词主读音，不按书覆盖）。
- **contract**：三书 + 综合。词库 `ph` = `ˈkɒntrækt`（名，未改），动词 `kənˈtrækt` 仅展示层；六级已补「收缩」义。
- **lie**：不需要读音变体——躺/位于/说谎/名词均为 `/laɪ/`，用词形区分（`lay/lain` vs `lied/lied`），避免展示层重复同一读音。
- **已落地（Lead 集成时补入展示层）**：lead（动 `liːd`；名词「铅」`led`）、object（名 `ˈɒbdʒekt`；动「反对」`əbˈdʒekt`）——两者释义都同时收了名/动义，读音不同；同属词键控展示层，词库 `ph` 未改。
