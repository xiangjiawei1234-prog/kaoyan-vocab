# 工具总览

独立小工具，双击各自目录下的 `index.html` 即可用，不依赖主应用、不共享学习进度。

| 工具 | 路径 | 用途 |
|:--|:--|:--|
| 完形搭配卡片 | `tools/collocation/` | 166 条真题固定搭配，卡片式记忆 |
| 复习计划表 | `tools/ebbinghaus-plan/` | 按开始日期与每日新词量生成艾宾浩斯计划 |
| 词频图 | `tools/wordfreq-viz/` | 查真题词频、看分布，辅助定筛选范围 |
| 长难句拆解 | `tools/long-sentence/` | 28 句真题长句，划主干/看分层结构与译文 |
| 作文模板 | `tools/writing/` | 小作文 9 类 + 大作文 4 类 + 高分句型 50 条 |
