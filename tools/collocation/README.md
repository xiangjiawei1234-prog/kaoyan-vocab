# 完形填空固定搭配 · 记忆卡片

考研英语完形填空「固定搭配」卡片式背诵小工具。收录 166 条搭配、183 处真题出现，数据已内嵌进页面，**双击即可离线使用**，不依赖网络与本地服务器。

## 打开方式

用浏览器直接打开本目录下的 `index.html`（双击，或拖进浏览器窗口）：

```text
tools/collocation/index.html
```

无需构建、无需 npm；手机浏览器同样可打开（把整个 `tools/collocation/` 拷到手机后打开 `index.html`，或用任意静态服务托管本目录）。

## 功能

| 功能 | 说明 |
|:--|:--|
| 卡片记忆 | 正面：英文搭配 + 可选真题例句挖空；点击 / 空格翻面。背面：中文释义 + 真题原句（答案高亮）+ 全部出处年份与题号 |
| 认识 / 不认识 | 两键判定；「不认识」自动进错题本，「认识」移出错题本并记入已掌握 |
| 筛选 | 范围（全部 / 错题本）· 类型（动词短语 / 介词搭配 / 名词搭配 / 形容词搭配 / 副词连接短语 / 其他）· 出现次数（不限 / ≥2 / =2 / =1） |
| 乱序 | 可开关；基于 seed 的确定性乱序（mulberry32），同 seed 结果可复现，可「按 seed 重排」或「换 seed」 |
| 进度统计 | 本轮 x/y、认识率、错题本数量、已掌握 / 166 |
| 本地进度 | `localStorage` 键名 `collocation_v1`，记住掌握状态、错题本、筛选与 seed |
| 键盘 | `空格` 翻卡 · `J`/`1` 不认识 · `K`/`2` 认识 · `←`/`→` 切换 |

## 数据说明

- 166 条搭配来自 46 套真题完形填空中的 183 处「固定搭配」考点，去重合并。
- 例句中 `【】` 内为正确答案；`____` 为同句其他空格。
- 数据内嵌在 `data.js` 中（字段：`c` 搭配、`m` 释义、`t` 类型、`n` 备注、`k` 次数、`o[]` 出现记录）。
