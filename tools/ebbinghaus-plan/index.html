「第 N 批」= 第 N 天学的新词（含词号范围）。括号内为该批按第几档间隔回来。当日新词另有 +5 分 / +30 分 / +12 小时三次闪回，属当日巩固，不计入复习列。

伍间隔表（与主应用一致）

档位 间隔 距学习日 是否计入按日复习
按日复习公式（全部判「会」的理想路径）：
令某日为第 D 天，日级间隔集合 R = {1, 2, 4, 7, 15, 30, 60}（单位：天）。
当日到期复习 = 所有满足 D − d ∈ R 的历史第 d 批词量之和。
当日合计 = 当日新词 + 当日到期复习。
学习天数 L = ⌈总词量 / 每日新词⌉；计划跨度 L + 60 天（末批最后一次 +60 天复习）。
