# 考研英语作文模板与高分句型

考研英语（一/二）作文备考工具：小作文模板、大作文框架、高分句型库、随机抽句练习。内容手写整理，**双击即可离线使用**，无网络依赖、无构建步骤。

## 打开方式

用浏览器直接打开本目录下的 `index.html`（双击，或拖进浏览器窗口）：

```text
tools/writing/index.html
```

手机浏览器同样可用：把整个 `tools/writing/` 目录拷到手机后打开 `index.html`，或用任意静态服务托管本目录。

## 内容规模

| 板块 | 条目 | 说明 |
|:--|:--|:--|
| 小作文模板 | **9 类** | 建议信 · 邀请信 · 投诉信 · 感谢信 · 道歉信 · 推荐信 · 询问信 · 申请信 · 通知 |
| 大作文模板 | **4 类** | 描述图画 · 分析原因 · 给出建议 · 总结升华 |
| 高分句型库 | **50 条** | 开头 8 · 过渡 7 · 举例 6 · 对比 6 · 让步 6 · 因果 6 · 强调 5 · 结论 6 |

每一类模板均包含：

1. **结构骨架** —— 段落/句位怎么排；
2. **3–6 个可替换句型** —— 英文原句 + 中文意思 + 用法提示；
3. **一篇范文** —— 小作文 100–120 词，大作文 160–200 词（词数按空白分词统计，页面卡片上标注）。

## 功能

| 功能 | 说明 |
|:--|:--|
| 按类型筛选 | 小作文按 9 类信函/通知筛选；大作文按 4 个写作模块筛选；句型库按 8 类功能筛选 |
| 关键词搜索 | 句型库支持中英文关键词即时搜索 |
| 收藏句型 | 模板内句型与句型库条目右上角 ★ 收藏；「我的收藏」页集中查看（含出处标签） |
| 随机抽句 | 从句型库随机抽英文，先回想中文再显示答案；可标记「记住了」 |
| 本地进度 | `localStorage` 键名 `writing_v1`：收藏、已掌握、当前页签与筛选、练习计数 |
| 键盘（练习页） | `空格` 显示/收起中文 · `N` 换一句 · `M` 记住了 |

## 数据说明

- 全部内容在 `data.js` 的 `window.WRITING_DATA` 中：
  - `letters[]`：`id / title / en / scene / skeleton[] / patterns[] / sample{title,body}`
  - `essays[]`：同上，另含 `focus`（该模块写作要点）
  - `sentences[]`：`id / cat / en / zh / scene`（50 条高分句型）
- 句型 `id` 全局唯一（如 `suggestion-p1`、`s34`），收藏与掌握状态按 id 记录。
- 如需扩充模板或句型，直接编辑 `data.js` 后刷新页面即可，无需构建。

## 使用提示

- 模板的作用是**结构 + 地道表达**，考场上务必按题目替换人名、时间、事由，不要整篇硬套。
- 「分析原因 / 给出建议」两篇范文示范的是议论文常见因果—对策链，可和图画描写句型组合成完整大作文。
- 句型库优先背「功能标签清晰、替换槽位少」的句子，考前用「随机练习」滚动自测。
